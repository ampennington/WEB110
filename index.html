Flash and the Modern Web

How Adobe Flash Shaped the Modern Web

Adobe Flash was a multimedia software platform, commonly recognized for its ability to create interactive web content and animations. Flash was able to display rich media content directly in web browsers. Flash would display text, vector graphics, and raster graphics to allow for animations, video games, and applications. It allowed audio and video streaming, and could capture mouse, keyboard, microphone, and camera input allowing for the ultimate interactive experience.

Technology rapidly changed, with the rise of HTML5 and other modern web standards, Adobe Flash quickly became irrelevant. Flash slowly withered out and reached the end of its life in 2020. The end of Flash made way for a larger shift in the way websites were designed and used.

About this Project, and Motivation

This website is for users to explore what Flash was, and what its legacy means for the modern web.

This project was created as a final project for WEB110. I wanted to explore what Flash was and how it influenced web development. I grew up playing Flash games and using Flash websites, I always enjoyed how interactive everything could be. The end of Flash devastated me, but as I completed this course and learned more about web development, I was inspired to compare how Flash held up against the modern web.
